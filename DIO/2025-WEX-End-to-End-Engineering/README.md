# WEX - END-TO-END ENGINEERING

**Informações:** [WEX - End to End Engineering](https://web.dio.me/track/wex-end-end-engineering)

Do fundamentos do back-end com devOps a uma possível contratação na Wex!

A WEX precisa de profissionais end to end Engineers e essa é a oportunidade de se tornar exatamente um perfil para contratação!

Aprender desde os fundamentos de .NET e C#, até a implementação de banco de dados, containers com Docker, qualidade de software e nuvem com AWS. Construa a possibilidade de ser um dos selecionados para as vagas (inclusive afirmativas para PcD).
